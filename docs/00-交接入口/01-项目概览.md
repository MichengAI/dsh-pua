# 项目概览

更新时间：2026-09-12 20:56（Asia/Shanghai）

DSH PUA 是 PUA 3.5.1 的社区 DSH 实现，包名 `@michengai/dsh-pua`。完整保留原版核心、展示、角色和风味协议，并以原生接口移植失败候选、质量纠偏与显式循环验收。

采用严格 TypeScript、ESM、Node.js >=22.19，开发宿主 DSH 0.1.5-rc.2，兼容 0.1.2-rc.1、0.1.5-rc.1。0.3.0 的插件配置页提供全局持久参数，聊天栏面板与命令只覆盖当前会话，子代理默认不启用 PUA；资料工具读取固定版本原文。新版持久终端的文本状态仅提示核验，不直接累计为失败。团队资源与权限策略使用 DSH 宿主能力，平台差异见[插件架构](../03-技术架构/01-插件架构.md)。

实现状态见[当前状态](02-当前状态.md)，安装和命令说明以 [README](../../README.md) 为准。
