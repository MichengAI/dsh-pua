# 项目概览

更新时间：2026-09-09 21:50（Asia/Shanghai）

DSH PUA 是基于 tanweai/pua 风味与方法论的社区 DSH 任务增强插件，包名 `@michengai/dsh-pua`。

目标是在当前会话显式开启工作模式，让 Agent 诊断后执行、无效重试时换方法、交付前核对证据。采用原生命令、动态提示词和可选的只读 Git 索引预检，不提供自动循环或团队调度。

实现使用严格 TypeScript、ESM、Node.js >= 22.19，验证接口基线为 DSH 0.1.2-rc.1。原版风味素材按文件指纹固定，单次提示词只包含当前风味。

源码初始化、当前验证与发布状态见[当前状态](02-当前状态.md)；安装和命令说明以 [README](../../README.md) 为准。
