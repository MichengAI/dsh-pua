# Web 配置与会话覆盖实现验收

更新时间：2026-09-12 23:43（Asia/Shanghai）

## 交付范围

0.3.0 提供「设置 → 插件 → PUA 配置」和权限右侧 PUA 会话入口。全局参数保存到当前 profile，会话按字段继承，可单项或全部恢复。命令仅写当前会话，不更改全局；关闭保留普通角色，取消排队 Loop，旧日志保留原有角色重置语义。

新增默认关闭的子代理策略；开启后继承父生效配置，父关闭时子不可强制开启。Loop 表单使用本次参数快照，不修改验收默认。原版素材、工具消息顺序修复和旧版本兼容逻辑保留。

## 浏览器组件验收

通过 `node scripts/preview-ui.mjs` 启动离线夹具，浏览器运行真实客户端组件；transport 为内存夹具，不连接用户 DSH、不写真实 profile。

- 全局保存华为后会话 A/B 都继承；A 自定义腾讯后 B 仍是华为；A 全部恢复后重新继承华为。
- 默认子代理关闭；继承控件禁用且显示生效值，自定义来源显式可见。
- 模拟保存失败显示错误，重试成功；错误不会被周期刷新自动吞掉。
- Escape 关闭模态框并把焦点返回 PUA 入口；修复了先移除 dialog 导致焦点落到 body 的问题。
- 默认视口与 390×844 窄屏目视检查，窄屏文档宽度 390px，弹窗 356px，无横向溢出，内容可以纵向滚动。
- Loop 表单空任务不能启动，填写任务后提交和取消分别显示反馈；夹具不执行验收命令或模型调用。
- 浏览器错误日志为空。专家位置为布局示意，实际插槽顺序依据专家插件和宿主源码，未宣称真实桌面联合验收完成。

此为 0.3.0 验收快照，安装和提交情况属于当时状态；最新情况以当前状态为准。真实模型、专家联合任务、桌面插件组合及钉钉原会话复测仍见[待办](../../../00-交接入口/03-待办与阻塞.md)。
