# 配置入口与直接编辑优化

更新时间：2026-09-12 23:14（Asia/Shanghai）

## 修正

用户实测指出两处交互不符合预期：全局配置误放独立 TAB；会话参数需要先切换来源才能编辑。

0.3.1 改用官方 `settings.plugin.item`，key 为已有 settings 命名空间 `michengai-pua`。官方首个“插件配置”TAB 将它与其他插件卡片一起显示，可展开，不新增 TAB。配置数据和 Remote 写入路径不变。

会话参数始终可编辑，未改项自动继承；修改即覆盖。去掉来源下拉框和重复生效值，只对覆盖项显示“已自定义”和“恢复默认”，保留全部恢复默认。

## 验证

- 先修改客户端 bundle 入口断言，旧实现因注册 TAB 而失败；修正后 `npm run check` 82 项通过。
- 浏览器组件实测：全局卡片默认折叠、可展开保存；会话无需切换来源即可从华为改腾讯，出现单项恢复；恢复后回到全局华为且控件仍可编辑。
- 该预览使用真实组件和内存 transport；实际桌面加载仍需后端重载后确认，不把预览等同于官方页面联合验收。
