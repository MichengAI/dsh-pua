# 审查问题修复验收

更新时间：2026-09-12 23:14（Asia/Shanghai）

## 范围与处理

0.3.7 修复已复核的运行状态、配置和反馈问题。沿用 I005，不改写旧版本的验收数字。

- 工具状态：仅统计本会话仍可见的调用；结束轮次或进入新轮次时解除历史孤儿阻塞。不会补造工具结果，也不负责修复宿主自身缺失结果的历史。卸载期间活跃组仍等待安全边界；会话销毁仍无法落库时明确告警并释放待写引用，避免无限保留监听。此情形未落库的观察会丢失，不能声称持久化成功。
- 配置：无 settings 时 Remote 可激活，默认关闭、会话命令仍可使用；全局写入给出明确不可用错误。全局关闭仍隐藏聊天入口。读取连接失败与已关闭分开，不把网络错误改写为关闭状态。
- 长度：结构化配置/Loop JSON 传输上限为 128 KiB，以容纳 JSON 转义；任务 4096 字符、verify 8192 字符仍按各字段校验。普通命令保留 8 KiB。两处验收命令输入框限制 8192 字符，设置 schema 同步。
- 版本：只有实际覆盖项变化才推进会话 revision；从未覆盖变为同值覆盖仍算变化，恢复继承也算变化。父级禁止的子会话开启保留覆盖意图，但保存反馈明确说明未实际生效。
- 观察：成功终端结果清除连续失败观察，EPERM/EACCES 等权限边界不计为结构化失败；每个用户轮次最多四次候选，保留原版模板。素材结构异常只告警并跳过候选，不打断模型步骤。
- 交互：官方 Switch 用隐式标签关联，点击文字可切换；忙碌时 aria-expanded 与菜单状态一致。清空数字不转换为 0；校验错误在表单展示中文。无效 JSON、空 verify 引号给出准确错误，空任务 token 不残留前导空格。
- Oracle：保留原生程序非零退出码；超时标记允许前导空行。
- 工程：CI 增加兼容矩阵；脚本拒绝空测试集和无有效计数的结果。未对历史代码做整文件格式重排。
