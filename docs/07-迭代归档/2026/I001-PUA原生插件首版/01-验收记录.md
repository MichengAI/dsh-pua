## 可复现方式

在源码目录执行：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
npm ci --ignore-scripts
npm run check
npm pack
```

包级检查使用 `scripts/smoke-package.mjs <隔离安装目录>`。该脚本不自行安装依赖、不访问 profile；只加载指定目录内已安装的包及宿主服务。

最终包同样在第二个新目录完成离线安装与冒烟检查。清理 `.test-tmp/package-smoke` 与 `.test-tmp/package-smoke-final` 时，合并命令和随后使用明确绝对路径的删除命令均被自动审批拒绝，理由仅为 `blocked by policy`。未绕过该限制，两个目录保留且已被 Git 和 npm 打包排除。
