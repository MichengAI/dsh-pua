## 工程取舍

- Git 预检通过可选 `ctx.get('subprocess')` 使用宿主执行环境；Cordis 当前 Inject 没有 optional 字段，不虚构注入参数。无服务仍可使用其他命令，review 明确说明证据不可用。
- 固定 argv，不把用户范围作为命令行；通过当前会话 cwd 定位根目录，并用 `:/` 路径规格读取全仓索引。清除 Git 仓库局部环境、关闭 fsmonitor 和可选锁。
- 总预算 10 秒，单次 stdout 1 MiB、stderr 8 KiB，无溢出落盘；不完整结果不产生计数。完整索引提供数量和有界样本，不等于完整文件审查。
- 异步预检完成前不暂存激活；取消或卸载中止预检，不发起模型请求。并发 off 按命令进入顺序在完成和恢复后仍生效。
- 0.1.0 历史误输入已作为任务成功执行时，按旧版成功结果恢复，不能用新版解析器悄悄重写旧状态。
- 原版素材保留 Windows 检出字节；19 份与固定提交内容一致，差异仅 CRLF。清单同时记录本地 SHA-256 与 Git 对象 SHA-256。
